# Memory Flip Card Game

A lightweight and interactive memory matching game built with HTML, CSS, and JavaScript.  
The goal is simple: flip the cards, remember their positions, and match all pairs in the shortest time.

### 🚀 Demo

## Overview

This project demonstrates core JavaScript concepts such as:

- DOM manipulation
- Event handling
- Timers (`setInterval`, `setTimeout`)
- Array shuffling
- Dynamic element creation
- Simple game logic design

## Tech Stack

- HTML — Structure
- CSS — Layout & animations
- JavaScript— Game logic
- FontAwesome — Icons used for cards

## Features

- Randomized card positions on each reload
- Card flip animations
- Timer that tracks gameplay duration
- Game-completion popup with play-again option
- Fully responsive grid layout
- Clean and easy-to-read code structure
